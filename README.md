# PostPilot

## Опис
"PostPilot" — сайт для публікації новин або статей на різноманітні теми. Це зручна платформа для тих, хто хоче ділитися своїми думками, дослідженнями або новинами з аудиторією. Сайт має сучасний дизайн, а також інтерактивні елементи для зручності користувачів.

## Технології
- HTML5
- SCSS
- JavaScript
- Адаптивна верстка (Flex, Grid)
- Система навігації по категоріях
- Форми для додавання контенту

## Демо
[PostPilot](https://vitiok2021.github.io/postpilot/) — сайт для публікацій новин

## Особливості
- Адаптивний дизайн для різних пристроїв
- Інтерактивні елементи для зручності користувача
- Простий та зручний інтерфейс для публікацій контенту
